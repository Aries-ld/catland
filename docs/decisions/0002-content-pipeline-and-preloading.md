# 0002 内容管线与预加载策略

- 状态：已接受（服务端已实现；客户端部分在开发 macOS App 时落地）
- 日期：2026-10-26

## 目标

刷起来的手感、布局、时延要和抖音 / 小红书一致：

| 指标 | 目标 | 服务端实测（xhs + bilibili + x） |
|---|---|---|
| 冷启动首屏 | < 2s 出第一张卡片 | 0.8–1.5s |
| 划到下一条的等待 | 接近 0（卡片已就绪） | p50 0ms，max 3ms |
| 划到下一条的首帧 | < 150ms（已预载）；未预载 < 2s | 客户端待测；冷播放 xhs 1.2s / B 站 1.7s / X 3.1s |

## 实测结论

- 各平台媒体 CDN 的防盗链要求不同：B 站必须带 Referer + UA，X **带错 Referer 反而 403**，xhs 不需要。请求头按平台随卡片下发。
- B 站 `catbus item media` 返回分离的 DASH 音视频轨：AVPlayer 合轨冷启动约 9s，且时长识别错误。改走网页 H5 播放器的公开 MP4 接口（720P、音视频合一），首帧约 1.7s。匿名请求需要先领访客 buvid，否则 412。这是 catbus 之外唯一的直连请求，不带登录态。
- xhs 推荐流只有封面，`item get` 一次拿到全文、图集和 MP4。
- X 推荐流里纯文字推文很多，刷刷流里先过滤，只放有画面的内容。

## 服务端（apps/sidecar/src/content）

- `PlatformAdapter`：每个平台负责取推荐流、解析成可直接播放的 `FeedCard`（媒体地址 + 请求头 + 尺寸 + 时长 + 过期时间）。
- `FeedMixer`：
  - 后台始终保持 `max(6, 3 × 平台数)` 张已解析卡片，`next()` 直接从缓冲区取。
  - 补货时优先补「待播 + 解析中」最少的平台；下发时优先最近出现最少的平台，同一平台最多连续 2 条。
  - 按平台限速：翻页间隔 ≥ 2s，解析间隔 ≥ 250ms；catbus 层同平台并发 ≤ 2。
  - 去重：本次会话内 + 已看过（SeenStore，后续落 SQLite 跨会话）。
  - 故障按平台隔离：风控冷却 10 分钟；登录失效暂停并通知；网络错误指数退避（5s 起，上限 2 分钟）；单条解析失败直接跳过，连续 3 次才退避。
  - 卡片距过期不足 60s 不下发，重新解析；播放失败时客户端调 `refresh(key)`。

## 客户端（macOS App，待实现）

1. **播放器池**：上一条 / 当前 / 下两条共 4 个 AVPlayer。下两条提前创建 AVPlayerItem 并预缓冲 3–5s（`preferredForwardBufferDuration`），当前条正常缓冲；划走的条目释放。
2. **封面先行**：切到下一条时立即显示封面（已预取），视频首帧到了再淡入，感知上零等待。
3. **图片预取**：接下来 5 张卡片的封面，以及图集的前 3 张，提前下载进 URLCache（磁盘 200MB）。
4. **评论**：在当前条停留 ≥ 2s 后预取评论第一页，打开评论面板时直接显示。
5. **手势**：
   - 触控板双指上下滑一次只翻一页，过滤惯性滚动。
   - 键盘 ↑↓ / J K 翻页，空格暂停，L 点赞，C 评论。
   - 翻页用弹簧动画。
6. **布局**：
   - 竖屏 9:16 面板。
   - 横屏视频居中，背景铺封面高斯模糊（抖音式）。
   - 图文横滑轮播加指示点（小红书式）。
   - 右侧操作栏：点赞、收藏、评论、在原 App 打开。
   - 底部：作者、标题、可展开的正文；角标显示来源平台。
7. **出错兜底**：播放 403 或超时就调 `refresh` 换新地址重试一次，仍失败则自动跳到下一条并提示一句。

## 补充：分散请求与风控降级（2026-10-27）

目标：单个平台的请求频率始终压低；某个平台被限流时用户无感。

- **分散**：混排优先补「待播 + 解析中」最少的平台，每个平台有独立的缓冲额度；同一平台最多连续 3 条。
- **限速**：每个平台每分钟最多 30 个请求（翻页 + 解析），匿名访问播放地址的 Bilibili 为 20；翻页间隔 ≥ 2 秒、解析间隔 ≥ 0.25 秒。
- **风控降级**：遇到 `RISK_CONTROL` 只冷却该平台，冷却从 5 分钟起、连续被拦逐次翻倍（最长 60 分钟）；同一次风控里的并发报错不叠加。冷却期间不推该平台，其他平台照常。
- **探测恢复**：冷却结束先只放行一个请求，成功才恢复正常供货、清零计数；再被拦则进入更长的冷却。
- **用户感知**：不弹风控提示；连接面板该平台显示「休息中 · 稍后自动恢复」；只有全部平台都在冷却时，刷刷页提示「各平台都在歇口气」。登录失效仍会提示（需要用户重新连接）。
