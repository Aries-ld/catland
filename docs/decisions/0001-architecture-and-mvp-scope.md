# 0001 架构与 MVP 范围

- 状态：已接受
- 日期：2026-10-26

## 背景

catbus 只提供 CLI（无库导出），单次调用数秒；feed 不带媒体地址，视频 CDN 需防盗链头；淘宝搜索 / 详情尚未实现。产品形态要求常驻 macOS 刘海。用户要求整个应用收敛在本机，为后续接入交易所等高敏感数据源打基础。

## 决策

1. **纯本地**：没有 catland 自己的服务器、账号体系、遥测或崩溃上报。所有网络请求只发往用户主动连接的平台本身。
2. **客户端**：Swift 原生（SwiftUI + AppKit），刘海区域用无边框 `NSPanel` 模拟灵动岛，无刘海机型退化为顶部居中胶囊；播放用 AVPlayer。
3. **本地服务**：Node sidecar 包装 catbus CLI，由 App 作为子进程启动、随 App 退出；与 App 走 **stdio JSON-RPC**，不监听任何端口（避免被本机其他进程或网页调用）。负责预取队列、媒体地址解析、限速与缓存。
4. **视频播放**：防盗链头由 Swift 侧 AVURLAsset / resource loader 直接附加，不起本地 HTTP 代理；若某平台必须代理，只绑 127.0.0.1 + 随机端口 + 一次性 token。
5. **密钥存储**：内容平台登录态沿用 catbus 的 `~/.catbus/`（0700/0600）；catland 自己新增的密钥（未来如交易所 API key）一律存 macOS 钥匙串，不落明文文件、不进日志。
6. **互动数据只存本地**：点赞、收藏、历史存在本地 SQLite（`~/Library/Application Support/catland/`），不回写原平台。
7. **MVP 范围**：连接面板 + 登录、灵动岛 + 小猫动画、视频/内容板块。电商板块延后到 v2。
8. **catbus 版本**：0.2.1。

## 影响

- 只支持 macOS。
- 首屏与下滑流畅度依赖 sidecar 的预取策略。
- 无法做云同步、多设备收藏同步；如未来需要，只能走用户自有的 iCloud / 本地导出。
- 电商一键比价受上游能力限制，v2 时重新评估。
