# ADR 0004：跨平台搜索

- 状态：已采纳（v0.3）
- 线框稿：`docs/design/v0.3-search.png`

## 背景

catland 现在只能刷推荐流。用户想看某个主题（「露营装备」）时，还得分别打开几个 App 搜。跨平台搜索把「一次搜遍小红书、抖音、B 站、快手」做成 v0.3 的主打功能，价值一句话就能讲清。

catbus 四个平台都实现了 `item search`（快手只能按关键词，没有排序 / 类型筛选），实测都返回封面、标题、作者、互动数和翻页游标（`#skip=N`），够渲染封面网格。平台请求仍然全部经 catbus，不新增 `docs/catbus-gaps.md` 里的例外。

## 决定

### 交互

1. **入口**：展开面板顶栏右侧的放大镜；快捷键 Cmd+F（只在面板展开时生效：收起时 App 不是前台，拿不到按键，也不和别的 App 的 Cmd+F 冲突）。第一次升级后冒一次「新：一次搜遍四个平台」提示。
2. **搜索页**：顶栏变成搜索框，推荐流暂停。下面是平台筛选（全部 / 单个已连接平台）、最近搜索（只存本机，可清空）。**只在回车时搜索**，不做边打字边搜。
3. **搜索中**：「猫们出门帮你找了…」，每只猫去自己的平台，谁先回来谁的结果先显示；筛选条显示各平台带回的条数。
4. **结果**：两列封面瀑布流，封面左上角平台图标、视频右下角时长；按平台轮流混排（同一平台最多连着 3 条）；滑到底加载下一页。
5. **点开**：进入和推荐流同一套竖向播放卡片，在搜索结果里上下切换；`< 关键词` / Esc 回到瀑布流原位置；「取消」回到推荐流，接着刚才那条播。

### 搜索会话（和小红书 / 抖音一致）

| 操作 | 结果 |
|---|---|
| 进入搜索、或搜索框为空 | 搜索首页：历史记录 + 猜你想搜 + 猫们会去哪儿找（没连平台时有「去连接平台」按钮） |
| 「取消」/ Esc 退出搜索 | 会话结束：清空关键词和结果；下次进来是干净的搜索首页（词留在历史记录里） |
| 搜索框的 ×、或把关键词删光 | 立刻回到搜索首页，旧结果丢掉，在途请求作废 |
| 空搜索框回车 | 不做事 |
| 改了字但没回车 | 保留旧结果，回车才换（不边打字边搜） |
| 播放里 Esc /「< 关键词」 | 回到瀑布流原位置；再 Esc 才退出搜索 |
| 搜索中途收起面板 | 只算暂停，再展开回到原处；隔超过 30 分钟再展开则结束搜索、回到推荐流 |

- **历史记录**：最近 10 个关键词，只存本机；点词直接搜。垃圾桶进入编辑（每个词出现 ×，单个删除 / 全部删除，「完成」退出），也可以右键删除单个。
- **猜你想搜**：有实时热搜时**只显示热搜**，不和本地词混在一起；一个都没有时才用本地示例词（按季节和时段挑选）。词前不带平台图标。「换一换」每次翻 8 个，热搜只有一组时不显示按钮。已在历史记录里的不重复出现。
- **热搜怎么取**：sidecar 后台定时取（`SearchService.startHotSchedule`）：每 5 分钟最多取**一个**平台（缓存最旧、超过 1 小时的那个），把请求分散开；风控冷却 / 登录失效跳过，catbus 没实现的平台记住、不再请求。`search.hot` 只读缓存、不发请求，各平台的热搜**等比例轮流混合、去重**。App 启动后 15 秒同步一次、之后每 30 分钟同步一次，并存到本地，打开搜索页时直接显示，不会先闪本地词。目前 catbus 只有小红书实现了热搜（`docs/catbus-gaps.md` 第 4 条）。

### 接口（sidecar）

| 方法 | 参数 | 返回 |
|---|---|---|
| `search.query` | `query`、`platform`、`cursor?` | `{ status, hits, cursor, hasMore }`，`status` 为 `ok` / `resting`（该平台在风控冷却）/ `auth`（登录失效） |
| `search.resolve` | `key` | `FeedCard`（解析出可播放媒体，供播放卡片使用；同时记入快照，点赞 / 收藏 / 评论照常可用） |

- 由 App 对每个已连接平台**分别**调用 `search.query`，各自返回，天然实现「谁先回来先显示」。
- `SearchHit`：`key platform id url kind title author cover stats duration`，不解析媒体（网格只要封面）；点开时才 `search.resolve`，并预解析后面两条。
- 一次搜索每个平台只取一页（10 条）；「加载更多」再按游标各取一页。

### 风控

- 搜索和推荐流**共用每个平台的风控状态**：平台在冷却中时 `search.query` 直接返回 `resting`，不发请求；搜索里遇到 `RISK_CONTROL`，同样让该平台进入冷却（推荐流也随之暂停它），冷却规则沿用 ADR 0002。
- 同一平台两次搜索请求至少间隔 2 秒；同一关键词同一页 5 分钟内命中缓存，不重复请求。
- `AUTH_*` 返回 `auth`，App 引导重新连接。
- 用户无感：筛选条上该平台显示「休息」，不弹错误；所有平台都不可用时才在结果区说明。

### 本地数据

- 最近搜索：App 本地保存最近 10 条关键词（UserDefaults），可一键清空；不上传、不回写平台。
- 搜索结果不写入「看过」记录；点开播放后才和推荐流一样记录浏览历史。

### App 实现

- `SearchController`（`apps/macos/Catland/Search/`）：每个平台一个状态（在找 / 带回 N 条 / 休息 / 要重新登录 / 没搜到）；结果按平台轮流**追加**（已经显示的不重排），同一平台最多连着 3 条；换关键词后丢弃旧请求的返回；第一页都回来、滑到底才加载下一页。
- 播放：`SearchController.player` 是第二个 `FeedController`，数据源换成「依次 search.resolve 接下来的 2 条」；`AppState.activeFeed` 决定键盘、滚轮、暂停作用在哪一套卡片上。
- 调试：`catland-debug search:` / `search:<关键词>` / `search:play:<序号>` / `search:close`。

## 不做（v0.3）

- 边打字边搜、搜索联想（`keyword suggest`）：请求多，风控风险高。
- 排序 / 时间 / 类型筛选：各平台取值不同，先统一用默认的综合排序。
- 搜用户、搜直播。

## 更新（v1.0.x）

- **信息源可勾选**：搜索首页「猫们会去这些地方帮你找」的每只猫是一个开关，默认全选、每次进入搜索恢复全选，至少留一只；没勾选的猫趴下打盹、显示「这次不去」。
- **翻页**：取消第一页回来后的后台预取，滑到当前结果的六成左右才按游标取下一页（底部转圈兜底）。限速见 ADR 0002「请求节奏」，搜索和推荐流共用平台预算。
- **封面**：搜索结果和点赞 / 收藏共用同一套封面瀑布流（`CoverGrid.swift`），格子按封面真实宽高比；有时长才显示时长，拿不到（B 站、小红书搜索）只显示播放标记。

推荐流的信息源：再点一下顶栏「视频」标签弹出平台开关（`SourcePicker`），或在「连接」页每个已连接平台的「刷它 / 不刷」开关，两处是同一份设置（`settings.sources.content`）；设置页不再重复提供。
