# catland 官网 · 产品文档（v1 草案）

> 设计稿：`docs/website/design-desktop.png`（桌面端整页长图，`scripts/mockup_site.py` 生成）。

## 1. 目标

| 目标 | 衡量 |
|---|---|
| 访客 **5 秒内**看懂 catland 是什么：在 Mac 刘海里刷常用的内容 App | 首屏停留后继续下滑的比例 |
| 看完演示就想装：下载按钮在首屏和结尾各一次，永远指向最新版 | 下载按钮点击数 / 访客数 |
| 新版本发布后网站**自动更新**，不需要改网站 | 发版到网站显示新版本的时间 < 1 分钟 |
| 中英双语，为 V2EX、即刻、小红书和 Product Hunt、Show HN 共用同一个落地页 | — |

**受众**：用 MacBook 的打工人、开发者、设计师。碎片时间不想拿手机，也不想切窗口。

**一句话定位**
- 中：在 Mac 刘海里，刷你常刷的 App。
- EN: Your favorite feeds, living in your MacBook notch.

## 2. 核心体验：整页就是一块 MacBook 屏幕的顶部

页面最上方固定一个**真实比例的刘海**，catland 的小岛住在那里，四只像素猫在里面走来走去。往下滑的过程，就是一次使用 catland 的过程：悬停 → 展开 → 刷 → 搜 → 看窗外 → 收起。演示都在网页里实时播放，滑多少动多少，往回滑会倒放；不是一张张截图。

## 5. 新版本自动上架

- 网站加载时读 GitHub Releases 的最新版本（`/repos/Aries-ld/catland/releases/latest`），显示版本号、日期、更新内容，下载按钮直接指向最新的 DMG。
- 读取失败（限流、网络）时，按钮跳到 `github.com/Aries-ld/catland/releases/latest`。
- 发版流程不变：只在 GitHub 发 Release，网站不用改。

## 6. 技术方案

| 项 | 选择 | 原因 |
|---|---|---|
| 框架 | Astro（纯静态输出） | 多语言路由（`/` 中文、`/en/` 英文）、打包小、SEO 友好 |
| 动效 | GSAP + ScrollTrigger | 滚动固定段、可倒放的时间线；各浏览器表现一致 |
| 像素猫 / 场景 | 从 App 导出的精灵图 + 场景序列帧，网页里用 canvas 播放 | 和 App 同一套美术，猫或场景改了重新导出即可 |
| 托管 | GitHub Pages + 自定义域名 + GitHub Actions 自动部署 | 免费、和代码同仓库，推送就上线 |
| 统计（可选） | Plausible / Umami 这类不用 Cookie 的统计 | 和 catland「不追踪」的气质一致；不需要也可以不加 |

**不需要**：数据库、后端服务、用户账号。

## 7. 性能、无障碍、SEO

- 首屏可交互 < 1.5 秒；图片 WebP / AVIF，序列帧按需加载。
- 系统开了「减少动态效果」时，关闭滚动动画，改成静态图。
- 移动端：保留内容和下载入口，滚动固定段改成普通纵向排列；提示「catland 是 Mac App，请用电脑访问下载」。
- 每种语言各自的标题和描述、Open Graph 分享图（用现在的主视觉）。
