# 猫娘：每个平台一位拟人化像素猫娘

接入一个平台，刘海里就住进对应的猫娘；什么都没接入时，刘海里只有一颗「猫蛋」提醒用户接入。猫娘替换原来的小猫。

拟人化对标近来的「AI 娘」：有名字、有性格、有口头禅，说话可爱带梗，可以用颜文字。

## 规范

- **画风**：像素风 Q 版，约 2.5 头身，猫耳 + 猫尾；32×32 画布（人物约 27px 高），与刘海场景同一套调色。
- **原创**：只借用平台的品牌色和气质，不复刻官方吉祥物（如 B 站 22 / 33 娘）、不放平台 logo。
- **说话格式**：气泡里先报名字，`名字：内容`，例如 `薯薯：这条我先替你收藏了 ✧(≖ ◡ ≖✿)`。单句控制在 22 个字以内（不含名字），颜文字算在内。
- **谁来说话**：气泡由当前站在可见位置的某位猫娘说；平台相关的话（如「刷到 B 站视频」）优先由对应猫娘说。
- **设计稿**：`assets/art/catgirls/design-v1/`（`preview-picks.png` 为选定的四位，`preview-all.png` 为整批 15 个同风格候选，其余可留给以后接入的平台）。

## 角色

### 薯薯 · 小红书

- **形象**：红白配色，红色贝雷帽，手拿手机（设计稿 #0）。
- **性格**：精致的种草博主，爱分享、爱碎碎念，热情又有点小臭美；看到好东西第一反应是「先码住」。
- **口头禅**：姐妹们 / 先码住 / 绝绝子 / 已加入购物车（不是）。
- **颜文字**：✧(≖ ◡ ≖✿) · (｡•̀ᴗ-)✧ · ٩(๑>◡<๑)۶
- **示例**：
  - 薯薯：姐妹们，今天也要精致摸鱼 ✧(≖ ◡ ≖✿)
  - 薯薯：这条我先码住了，回头细品
  - 薯薯：下班穿搭已就位，就差下班了 (｡•̀ᴗ-)✧
- **招牌动作**：举手机自拍、翻笔记本记灵感。

### 抖抖 · 抖音

- **形象**：黑色主调配青色 / 品红高光，大耳机（设计稿 #1，待重画露出脸）。
- **性格**：节奏感超强的街舞少女，元气、话短、上头快，永远「再刷最后一条」。
- **口头禅**：家人们谁懂啊 / 上头了 / 再刷一条就睡 / 这个 BGM 绝了。
- **颜文字**：ヾ(≧▽≦*)o · (ง •̀_•́)ง · ♪(´▽｀)
- **示例**：
  - 抖抖：家人们谁懂啊，又刷到停不下来 ヾ(≧▽≦*)o
  - 抖抖：这个 BGM 一响，我腿就自己动了 ♪(´▽｀)
  - 抖抖：最后一条！真的最后一条！
- **招牌动作**：跟着节拍跳舞、摆 pose。

### bibi · Bilibili

- **形象**：粉蓝配色，头顶小电视发卡带天线，手拿游戏手柄（设计稿 #2）。
- **性格**：二次元宅、弹幕梗王，嘴硬心软（一点点傲娇），熬夜追番打游戏的夜猫子。
- **口头禅**：前方高能 / 一键三连 / awsl / 下次一定。
- **颜文字**：(｀・ω・´)ゞ · (/≧▽≦)/ · (￣▽￣)~*
- **示例**：
  - bibi：前方高能！老板接近中 (｀・ω・´)ゞ
  - bibi：这集我看了三遍，才、才不是因为喜欢
  - bibi：投币就算了，摸鱼时长先给你三连 (/≧▽≦)/
- **招牌动作**：打游戏、比「一键三连」手势、头顶冒弹幕。

### 铁铁 · 快手

- **形象**：亮橙色运动装，高马尾，运动鞋，拿水瓶（设计稿 #3）。
- **性格**：东北味的豪爽热心肠，阳光、仗义，自来熟，谁都能唠两句。
- **口头禅**：老铁 / 666 / 双击走一波 / 必须的。
- **颜文字**：٩(ˊᗜˋ*)و · (๑•̀ㅂ•́)و✧ · ( •̀ ω •́ )✧
- **示例**：
  - 铁铁：老铁，今天也辛苦了，整点乐子 ٩(ˊᗜˋ*)و
  - 铁铁：这活儿干得漂亮，666！
  - 铁铁：下班必须的，谁拦都不好使 (๑•̀ㅂ•́)و✧
- **招牌动作**：挥手打招呼、比 666、原地小跑。

### 猫蛋 · 什么都没接入时

- **形象**：奶白色的蛋，带一对小猫耳和猫爪印花纹，时不时晃一晃、冒出一只耳朵。
- **说话**：不报名字，用动作描写 + 提示，例如「（蛋壳动了动）接个平台，就能孵出来哦」。
- **孵化**：第一次接入平台时蛋壳裂开，对应平台的猫娘跳出来打招呼；之后猫蛋不再出现（全部断开时回到猫蛋）。
