# 猫娘：每个平台一位拟人化像素猫娘

接入一个平台，刘海里就住进对应的猫娘；什么都没接入时，刘海里只有一颗「猫蛋」提醒用户接入。猫娘替换原来的小猫。

拟人化对标近来的「AI 娘」：有名字、有性格、有口头禅，说话可爱带梗，可以用颜文字。

## 规范

- **画风**：像素风 Q 版，约 2.5 头身，猫耳 + 猫尾；48×48 画布（人物约 46px 高），与刘海场景同一套调色。
- **原创 + 参考**：每位猫娘锚定一位动漫女角色找灵感（下文「形象参考」），只借发型、配色、服装轮廓和气质，混合成新角色，不画成一眼能认出的同人图；不复刻平台官方吉祥物、不放平台 logo。
- **性格参考真人时只借性格**：不提真人的名字，不用其标志性台词和形象。
- **说话格式**：气泡里先报名字，`名字：内容`，例如 `薯薯：这条我先替你收藏了 ✧(≖ ◡ ≖✿)`。单句控制在 22 个字以内（不含名字），颜文字算在内。
- **谁来说话**：气泡由当前站在可见位置的某位猫娘说；平台相关的话（如「刷到 B 站视频」）优先由对应猫娘说。
- **定稿**：`assets/art/catgirls/final/`（`preview.png` 为四位合照）。设计过程稿：`design-v1/`（第一批 32px，未采用）、`design-v2/`（按参考角色重做，每人 8 版）。

## 角色

### 薯薯 · 小红书

- **形象参考**：辉夜大小姐（四宫辉夜）——黑长直、红色系、大小姐仪态。
- **定稿**：黑长直、红眼，暗色长裙，撑一把深红色洋伞（`final/shushu.png`，design-v2 #5）。
- **性格**：精致高雅的女性，有点 mean（嘴上挑剔、毒舌），爱分享、爱碎碎念，有点小臭美；嫌弃归嫌弃，好东西一定第一个分享给你。
- **口头禅**：姐妹们 / 先码住 / 绝绝子 / 已加入购物车（不是）。
- **颜文字**：✧(≖ ◡ ≖✿) · (｡•̀ᴗ-)✧ · ٩(๑>◡<๑)۶
- **示例**：
  - 薯薯：姐妹们，今天也要精致摸鱼 ✧(≖ ◡ ≖✿)
  - 薯薯：这条我先码住了，回头细品
  - 薯薯：下班穿搭已就位，就差下班了 (｡•̀ᴗ-)✧
- **招牌动作**：举手机自拍、翻笔记本记灵感。

### 抖抖 · 抖音

- **形象参考**：我推的孩子（星野爱）——紫色长发、星星眼、偶像感。
- **定稿**：紫色渐粉的长双马尾、星星眼，粉黑偶像裙，握着麦克风（`final/doudou.png`，design-v2 #0）。
- **性格**：时尚潮妹，走在潮流最前面：穿搭、新梗、热门 BGM 门儿清，自信、酷、有态度，话短上头快。
- **口头禅**：家人们谁懂啊 / 上头了 / 再刷一条就睡 / 这个 BGM 绝了。
- **颜文字**：ヾ(≧▽≦*)o · (ง •̀_•́)ง · ♪(´▽｀)
- **示例**：
  - 抖抖：家人们谁懂啊，又刷到停不下来 ヾ(≧▽≦*)o
  - 抖抖：这个 BGM 一响，我腿就自己动了 ♪(´▽｀)
  - 抖抖：最后一条！真的最后一条！
- **招牌动作**：跟着节拍跳舞、摆 pose。

### bibi · Bilibili

- **形象参考**：更衣人偶坠入爱河（喜多川海梦）——金发渐变粉、辣妹风、元气。
- **定稿**：金发渐粉的侧马尾、项圈，宽松粉色卫衣（`final/bibi.png`，design-v2 #2）。
- **性格**：傲娇的二次元萌妹，嘴硬心软、「才不是为了你」，满嘴番剧和弹幕梗，熬夜追番的夜猫子。
- **口头禅**：前方高能 / 一键三连 / awsl / 下次一定。
- **颜文字**：(｀・ω・´)ゞ · (/≧▽≦)/ · (￣▽￣)~*
- **示例**：
  - bibi：前方高能！老板接近中 (｀・ω・´)ゞ
  - bibi：这集我看了三遍，才、才不是因为喜欢
  - bibi：投币就算了，摸鱼时长先给你三连 (/≧▽≦)/
- **招牌动作**：打游戏、比「一键三连」手势、头顶冒弹幕。

### 铁铁 · 快手

- **形象参考**：咒术回战（九十九由基）——高挑的大姐姐、金色长发、随性利落。
- **定稿**：浅金色长发、一只眼眨着，牛仔外套 + 牛仔裤，双手叉腰（`final/tietie.png`，design-v2 #2）。
- **性格**：东北大姐（性格参考东北农村生活类网红，只借性格）：嗓门大、豪爽、干活麻利、接地气、热心肠，自来熟，护短。
- **口头禅**：老铁 / 666 / 双击走一波 / 必须的。
- **颜文字**：٩(ˊᗜˋ*)و · (๑•̀ㅂ•́)و✧ · ( •̀ ω •́ )✧
- **示例**：
  - 铁铁：老铁，今天也辛苦了，整点乐子 ٩(ˊᗜˋ*)و
  - 铁铁：这活儿干得漂亮，666！
  - 铁铁：下班必须的，谁拦都不好使 (๑•̀ㅂ•́)و✧
- **招牌动作**：挥手打招呼、比 666、原地小跑。

### 纸箱猫娘 · 什么都没接入时

- **定稿**：白色长双马尾、蓝眼睛，缩在纸箱里只露出脑袋和爪子扒着箱沿，箱子上贴着猫爪纸条（`final/box.png`，design-v3-initial 纸箱 #3）。
- **作用**：没有接入任何平台时独自住在刘海里，提醒用户去接入。
- **性格**：怯生生又满怀期待的小可怜，等人领回家；说话软糯、句尾爱带「…」。
- **登场仪式**：第一次接入平台时，她从纸箱里跳出来欢呼，然后对应平台的猫娘登场；之后纸箱猫娘退场（全部断开时回到纸箱）。

## 语料实现

语料在 `apps/macos/Catland/Scene/PersonaCopy.swift`（每位猫娘的戳我 / 天气 / 季节 / 时段 / 星期 / 心情 / 倒计时模板），由 `BubbleCopy.rotation` 按已接入的平台轮流挑选；测试保证每句不超过 22 个字。
