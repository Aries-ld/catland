# 平台小猫：每个内容平台一只固定花色的手绘像素猫

刘海里的小猫代表平台的连接情况：**只有正常连接的平台，它的猫才在刘海里**。什么都没接入时，只有纸箱里的小奶猫「箱箱」提醒用户接入。

设计过程中试过两条路，都放弃了：
- 拟人化猫娘：刘海两侧太窄，人形角色只能原地踱步，表现力不如小猫，也偏离了 catland「各平台小猫住进同一片 land」的主旨。
- Meowa 生成的精细像素猫：和场景、原有小猫的画风不搭。

最终沿用原来手绘的 16×12 像素小猫（`PixelCatArt`），只给每只猫换固定花色、加一个小配饰。

## 规范

- **画风**：手绘像素猫，16×12 画布，1 个美术像素 = 1.5pt；动作沿用原有的整套（发呆、张望、坐下、舔爪、打哈欠、打盹、面包、伸懒腰、追蝴蝶、打滚、走路、蹦一下、看窗外、钻猫洞）。
- **辨识**：花色 + 一个 2–6 像素的配饰，跟着头的位置走（低头、趴下都跟着动）；不放平台 logo。
- **说话格式**：气泡里先报名字，`名字：内容`，单句不超过 22 个字（不含名字），颜文字算在内；气泡冒在说话那只猫的头顶。
- **样张**：`assets/art/platform-cats/sheet.png`（五只猫 × 常用动作）；刘海实拍：`assets/art/platform-cats/notch-states.png`。

## 状态表达

| 平台状态 | 刘海里的表现 |
|---|---|
| 正常连接 | 这只猫正常活动 |
| 刚连接上 | 从画面外走进来；如果之前一个平台都没有，箱箱先在纸箱里开心地蹦一下，然后连箱子一起退场 |
| 被风控、暂停中（`cooldown`） | 趴下打盹、冒 zzz，一直睡到恢复；悬停时只说「我累了，休息一会儿再来」这类话 |
| 登录失效 / 断开 / 暂未开放 | 这只猫淡出、不再出现 |
| 一个平台都没有 | 只有箱箱蹲在左侧的纸箱里，发呆、张望、打哈欠 |

小猫代表连接状态，所以不再「隔几分钟换一只随机花色的猫」；钻猫洞也改得更少、更短（同一时间最多一只，8–20 秒），避免看起来像是平台不在了。

## 实现

- **花色与配饰**：`apps/macos/Catland/Cat/PixelCatArt.swift`（`Skin.accessory`、`Accessory`、花棉袄涂装 `jacket`）；平台花色不参与随机路过（`platformSkins`）。
- **出场与行为**：`apps/macos/Catland/Cat/CatStage.swift`。`CatDirector.sync` 维护每个舞台的出场名单（新平台从画面外走进来、断开的淡出、箱箱蹦一下退场）；`tick` 处理打盹（`sleeping`）和箱箱（不走动、只做原地动作）；纸箱由 `drawBox` 画在小奶猫前面。
- **出场名单**：`AppState.speakers`（正常连接的内容平台，排除登录失效）与 `AppState.sleepingCats`（来源状态为 `cooldown`）。平台 → 名字 / 花色见 `Persona`（`apps/macos/Catland/Scene/PersonaCopy.swift`）。
- **语料**：`PersonaCopy.swift`（每只猫的戳我 / 打盹 / 天气 / 季节 / 时段 / 星期 / 心情 / 倒计时模板），`BubbleCopy.rotation` 按出场名单轮流挑选；测试保证每句不超过 22 个字。
- **调试**：`catland-debug cast:box` / `cast:shushu,bibi` / `cast:off`；`sleep:bibi` / `sleep:off`；`cats:dump`（打印每只猫的位置与状态到日志）。

## 以后接入的平台

微博、X、TikTok、电商平台开放时：在 `PixelCatArt.skins` 加一个花色（必要时加配饰），在 `Persona` 里登记名字、花色和语料，并在本文件补一行。
