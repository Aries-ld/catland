下午三点，编译还要跑八分钟。

你不想拿手机，一拿起来就是半小时；也不想切到浏览器，那一排标签页只会提醒你还有多少事没做完。你只是想喘口气。

于是你把鼠标往屏幕顶上轻轻一推。

那里有一座小岛。窗外是你所在城市此刻的天色，四只猫在窗台上晒太阳，有一只正在舔爪子。戴蝴蝶结的布偶猫抬眼看你：

> 薯薯：还不点？品味有待提高哦

点一下，小岛展开。小红书、抖音、Bilibili、快手的推荐揉成一条，一条一条往下刷。八分钟后编译跑完，你点一下别处，小岛收回去，什么都没发生过。

这就是 catland。

<br>

## 岛上的居民

<div align="center">
<img src="assets/brand/cats.png" width="92%" alt="薯薯、抖抖、bibi、铁铁，和纸箱里的箱箱">
</div>

你接入一个平台，就有一只猫搬上岛。

- **薯薯**，小红书家的布偶猫，头上一只红蝴蝶结。精致，嘴巴有点毒，看到好东西还是会第一个分享给你。「老板画的饼，本小姐不吃。」
- **抖抖**，抖音家的黑猫，戴一条会发光的项圈。什么梗都知道，什么 BGM 都会哼。「家人们谁懂啊，又上头了。」
- **bibi**，Bilibili 家的三花，脑袋上顶着两根小电视天线。嘴硬心软，熬夜追番。「才、才不是想让你点我。」
- **铁铁**，快手家的奶牛猫，常年一件东北花棉袄。嗓门大，热心肠，护短。「老板画饼？大姐给你烙个真的。」

一个平台都还没接的时候，岛上只有**箱箱**，一只缩在纸箱里的小奶猫，扒着箱沿等你把大家接回来。等第一只猫搬上岛，她会在箱子里开心地蹦一下。

看一眼小岛，你就知道哪个平台还连着：谁被平台限流了，谁就趴下打盹，头上冒 zzz，过一会儿自己醒来；谁的登录过期了，谁就暂时不在岛上。

它们还会跟你聊天。鼠标停在岛上，猫们轮流开口，各说各的：

> 铁铁：今天活儿干了 63%，麻溜的<br>
> bibi：这么晚了，快睡啦笨蛋<br>
> 薯薯：还有 3 天发工资，忍住别剁手<br>
> 抖抖：最后一条，真的最后一条

## 刷起来是什么感觉

和你在手机上刷短视频一样，只是不用抬头。

几个平台的推荐流混在一起，轮着来，同一个平台最多连着刷到三条；看过的不会再出现。下一条早在你看上一条的时候就准备好了，划过去几乎不用等。触控板一滑就是一页，视频的进度条可以拖，暂停时能看到播到哪儿了；图文笔记左右翻页，评论一点就开。

某个平台突然不给内容了，你不会看到报错。那只猫去打个盹，你照常刷其他平台的，等它恢复，它的内容会自己回来。

老板走过来时，按 `⌥ Esc`。小岛立刻收起，视频暂停。

## 窗外，和你同一片天

<div align="center">
<img src="assets/brand/scenes.png" width="92%" alt="小岛窗外的四季、昼夜、天气和夜空里的事件">
</div>

小岛的窗外不是一张壁纸。

太阳什么时候落、外面是晴是雨，都跟你所在的城市一致。位置用的是 Mac 的系统定位，挂着 VPN 也不会把你算到别的国家去。在北京，窗外是央视大楼和中国尊；在上海，是东方明珠和上海中心；在新加坡，是金沙酒店和摩天轮。其他城市的朋友，岛上会随机住进北京或上海的天际线，天色和天气还是你那里的。

窗外跟着季节换衣服：春天飘樱花，夏夜有萤火虫，秋天的树一点点变红，冬天窗角结霜、挂冰凌。春节挂灯笼，中秋有一整晚的满月。

偶尔，天上会有事情发生：真实流星雨极大日那晚的流星雨、夏夜的花火大会、滨海湾的灯光秀。猫们会提前几个小时告诉你「今晚 22:00 有流星雨哦」，到了时间，它们会停下手里的事，一起坐着看窗外。

还有一些不会提前说的小事。雨天的海湾里漂着一只纸船；工作日的上午，窗台上放着一杯冒热气的咖啡；运气好的话，你会看见 UFO。

## 你的东西，只留在你的 Mac 上

catland 没有服务器，不需要注册账号，不收集任何数据。

你在 catland 里点的赞、收藏的视频，只存在你自己的电脑里，不会同步回原来的平台，不会被拿去训练推荐，也不会出现在你的主页上。所有平台的「喜欢」，都收在同一个地方。

你的平台登录信息保存在本机的 `~/.catbus/`。catland 对外只连你接入的平台；唯一的例外是窗外的天气，查询时只发送精确到约 10 公里的坐标，不想要可以在设置里关掉。

## 安装

1. 到 [Releases](https://github.com/Aries-ld/catland/releases/latest) 下载 `catland-x.y.z-macos-arm64.dmg`（Apple 芯片）。Intel 芯片的 Mac 暂时没有安装包，可以按下面的步骤[从源码构建](#从源码构建)。
2. 打开 DMG，把 catland 拖进「应用程序」。安装包经过 Apple 签名和公证，双击就能打开。
3. 屏幕顶上会出现箱箱。点一下她，选「连接平台」：
   - 小红书、Bilibili、快手：用手机 App 扫一下二维码。
   - 抖音：在弹出的抖音官方页面里扫码或用验证码登录。

需要 macOS 14 或更新的系统。App 已经带好了运行需要的一切，不用另外装任何东西。在 MacBook 上，小岛就长在屏幕顶端摄像头的两侧；外接显示器和其他 Mac 上，它住在屏幕顶部正中间。

### 快捷键

| 做什么 | 怎么做 |
|---|---|
| 打开 / 收起小岛 | 点一下，或 `⌥ \`` |
| 老板来了 | `⌥ Esc`，立刻收起并暂停 |
| 下一条 / 上一条 | 触控板上下滑、滚轮、`↑` `↓` 或 `J` `K` |
| 图集翻页 | 触控板左右滑、左右拖动、`←` `→` |
| 点赞 / 收藏 / 评论 | 双击画面，或 `L` / `S` / `C` |
| 暂停 / 静音 | `空格` / `M`（默认静音） |

## 从源码构建

想自己改，或者用的是 Intel 芯片的 Mac？几分钟就能在本机构建：

```bash
# 准备（只需一次）：Xcode 16+、Homebrew
brew install node xcodegen             # Node 需要 26 及以上
git clone https://github.com/Aries-ld/catland.git && cd catland
(cd apps/sidecar && npm install)

# 直接运行开发版
apps/macos/scripts/run.sh

# 或者打包成和 Releases 一样的 DMG（产物在 dist/）
scripts/package-dmg.sh
```

也可以把下面这段话交给 Claude Code、Codex、Cursor 这类编码助手，让它替你做：

```text
请在我的 Mac 上从源码构建并安装 catland（https://github.com/Aries-ld/catland）：
1. 确认已安装 Xcode 16+；用 Homebrew 安装 node（26 及以上）和 xcodegen。
2. 克隆仓库，在 apps/sidecar 里执行 npm install。
3. 在仓库根目录执行 scripts/package-dmg.sh，按我的芯片架构打包 DMG（产物在 dist/）。
4. 挂载 DMG，把 Catland.app 拷到 /Applications 并打开它。
仓库里的 AGENTS.md 和 docs/development.md 有项目约定和更多命令。
```

## 几句要说清楚的

- catland 是一个开源的个人项目，**仅供学习研究，不做任何商业用途**。内容来自各平台的公开接口（通过 catbus），请遵守各平台的用户协议，不要高频请求。
- 各平台的名称和图标属于它们各自的所有者，这里只用来标明内容来源，catland 与这些平台没有任何关系。
- catland 不会替你在平台上点赞、评论、关注或发布任何东西。
